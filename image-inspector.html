How to read the results

The Image Inspector reads the file you choose inside your browser and shows what it finds. The file is not uploaded. Here is what each result means and how it is worked out.

  • Resolution, aspect ratio, file size and format — read straight from the file. "Format" is the file extension, and the file size is shown together with the file type your browser reports.
  • Color palette and dominant colors — the tool samples pixels across the image, rounds each color to a coarse step (eight levels per color channel) and lists the five most common results as hex codes. Transparent pixels are ignored. The palette shows what is most common in the image, not what stands out most to the eye.
  • Brightness and exposure — brightness is the average luminance of the sampled pixels. The exposure label only reports a bright, dark or balanced tendency; it cannot tell a deliberately dark photograph from an underexposed one.
  • Contrast — the spread of luminance across the sampled pixels, scaled to 0–100%. Flat, hazy images score low; images with strong blacks and whites score high.

Estimates and suggestions

The last three results are rough indicators, not measurements, so read them as hints.

  • Sharpness estimate — the average strength of local edges, measured on a reduced copy of the image (averaged down to at most 512 pixels on its longest side) so that a large file and a small file of the same picture score alike, then scaled to 0–100. Soft subjects such as fog or a plain studio backdrop score low even when they are in focus, so treat it as a rough indicator and check the image at 100% zoom.
  • Estimated compression — the file size divided by the number of pixels, in bits per pixel. For JPEG and WebP files the tool labels this as heavily, moderately or lightly compressed; for other formats it shows the figure without a label. It is an estimate: very different images can have the same bits-per-pixel value.
  • Editing suggestions — short tips triggered by simple rules, such as low brightness or a low sharpness score. They are not generated by AI, and they are a starting point rather than a verdict on the image.

The Image Inspector does not read camera (EXIF) metadata, does not judge whether an image is large enough to print, and does not send the image to any AI service.
