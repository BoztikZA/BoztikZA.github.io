Before you start

Install Boztik Creative Toolkit from the Chrome Web Store or the Microsoft Edge Add-ons store. After installation, open a webpage that contains an image. The browser may ask you to allow the extension on that site; access is permission-based, so grant it only on sites where you want to use the tools.

The exact layout can change between Toolkit updates. If a label or button looks different in your installed version, use the feature name and purpose described here as your guide, and check the Toolkit page for the current release information.

1. Image Inspector: your starting point

Image Inspector is the main hub. It helps you understand an image before you download, edit, print or share it. Select an image on a webpage and open it in the Inspector using the extension's available image action.

What the details mean

  • Dimensions: the image's width and height in pixels. A 2400 × 1600 image is 2400 pixels wide and 1600 pixels tall.
  • Aspect ratio: the shape of the image, such as 3:2 or 1:1. This helps you decide whether it will fit a frame or layout without cropping.
  • Megapixels: an approximate total pixel count. It is useful as a quick size indicator, but it does not tell you whether the image is sharp or well-focused.
  • Format: the file type, such as JPEG, PNG or WebP. Different formats suit different jobs.
  • File size: how much storage the file uses. Large files can take longer to upload or load on a webpage.
  • Source and metadata: information the browser can access about where the image came from and any embedded details. Some websites remove or restrict this information.

A useful example

If a client sends a photograph for an 8 × 10 inch print, check its pixel dimensions and aspect ratio first. The Inspector helps you understand what you have; it does not guarantee print quality on its own. Use the resolution and DPI guide for the next step.

2. Floating Boztik Button: quick image details

The Floating Boztik Button appears over supported images on webpages when the extension has permission to run there. Hovering over it can show a quick summary such as pixel dimensions, megapixels, aspect ratio, displayed size and an estimated print size at 300 PPI. Click the button to open the image in Image Inspector.

Use it when you want a fast check without opening the full Inspector. If it gets in the way, you can hide it for a particular website using the extension's available site controls. It is a shortcut, not a quality verdict: a large image can still be blurry, compressed or poorly exposed.

3. Find Original: look for the source image

Find Original helps you investigate where an image may have come from. Start with the image you want to trace and use the reverse-image-search option provided by the Toolkit. The search service compares visual content and may return visually similar images or pages that contain a match.

  1. Choose the image.Open it in Image Inspector and select Find Original.
  2. Review the search results.Look for the same photograph, not merely a similar subject or crop.
  3. Check the source page.Confirm the publisher, context, date and any licensing information before reusing the image.

Important

A reverse-image result does not prove who owns an image or grant permission to use it. Always check the original source and its licence or usage terms.

4. Print & Screen Check: assess suitability

This area helps you interpret image dimensions in the context of common screen and print uses. For print, pixel dimensions and the intended physical size determine the effective pixels per inch (PPI). For screens, the display dimensions and crop are often more relevant than a print-DPI label.

Use it as a planning check before sending a file to a printer or placing it in a design. It cannot assess every aspect of image quality: focus, motion blur, noise, compression artefacts and the printer or display itself also matter. Read Image Resolution and DPI Explained for a worked print example.

5. Palette Extractor: identify colours in an image

Palette Extractor samples prominent colours from an image and presents them as a usable colour palette. It is helpful when you want to build a design around a photograph, match a graphic to a brand colour family or explore a consistent set of tones.

  1. Open the image.Choose the image whose colours you want to study.
  2. Open Palette.Let the tool analyse the visible image and display its sampled colours.
  3. Choose colours deliberately.Use the palette as a starting point, then check contrast and readability in your actual design.

Photographs contain many subtle shades, so an extracted palette is a summary rather than a complete record of every colour. Check text contrast separately, especially for small text and buttons.

6. Image Lab: resize, compress and convert

Image Lab is for preparing an image for a specific destination. The three jobs are related, but they are not the same:

  • Resize: changes the pixel dimensions. Use this when an image is larger than the destination needs.
  • Compress: reduces file size, usually by changing encoding or quality. Stronger compression can introduce visible artefacts.
  • Convert: saves the image in another format, such as JPEG, PNG or WebP, where supported.
  1. Keep an original.Work from a copy so you can return to the source file if needed.
  2. Choose the destination.A website image, transparent logo and print master have different requirements.
  3. Set the output.Choose dimensions, format and compression settings appropriate to that destination.
  4. Inspect the result.Zoom in on edges, fine detail, gradients and text. Check the final dimensions and file size before using it.

Practical tip

Do not repeatedly resize and recompress the same JPEG. Keep a high-quality master and export a fresh copy for each use. See JPEG vs PNG vs TIFF for format guidance.

7. Colour Tools: work with colour values

Colour utilities help you inspect, choose or convert colour values for creative work. A HEX value such as #8eff3d is a compact way to specify a colour for web design. RGB describes red, green and blue light values; HSL describes hue, saturation and lightness.

Use the available Colour Tools controls to read or adjust values, then apply them consistently in your design software or website. Remember that the same numeric colour can look different on uncalibrated displays, and print output depends on the printer, paper and colour-management workflow.

8. Fonts: identify typography on a page

The Fonts tools help you inspect typography used on a webpage and explore font information. They are useful when researching a design, checking the typeface used in a heading or collecting visual references for your own layout.

When you identify a font, check its actual family name, available weights and licence before using it in a commercial project. A font appearing on a webpage does not mean it is free to download or reuse. Some sites also load fonts dynamically, so the information available to the browser may be incomplete.

9. Creative Assistant: get guidance, not guarantees

The Creative Assistant includes built-in reference guidance for common creative questions. Optional provider-powered AI features can connect to an AI service using your own API key. Those external services have their own terms, privacy policies and possible charges.

Use suggestions as a starting point, then verify important technical details in your own workflow. Do not send confidential client images or personal information to an external AI provider unless you understand and accept that provider's data handling terms.

Images, privacy and permissions

Core image inspection and capture features are designed to work locally in your browser and do not upload images to Boztik's servers. Some actions involve external services by design: reverse image search sends the image or its search representation to the selected search provider, and provider-powered AI features send prompts or relevant content to the AI provider you connect.

Website access is opt-in. The extension works on sites where you grant permission, and you can change site access in your browser's extension settings. Review the current Boztik Privacy Policy and the relevant third-party provider terms for full details.
