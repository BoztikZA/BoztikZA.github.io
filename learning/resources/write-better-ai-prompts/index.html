How to Write Better AI Prompts: A Practical Beginner's Guide

Better AI results usually start with a clearer brief. Learn how to give an AI assistant the context, task, audience, format and boundaries it needs.

7 min read · Published 2026-11-26 · Boztik Learning Editorial Team

Start with the job, not clever wording

A useful prompt is a short work brief. It tells the assistant what you are trying to achieve, what information it should use and what a good answer should look like. You do not need secret phrases or complicated prompt formulas.

Before writing, ask yourself three questions: What task am I delegating? What would I need to tell a capable colleague? How will I check whether the answer is good enough?

Use a simple five-part structure

  1. Context: Give the background that changes the answer. Include the audience, situation or relevant source material.
  2. Task: State the action clearly, using a verb such as compare, explain, draft, classify or calculate.
  3. Constraints: Set boundaries such as length, tone, date range, tools available or things the assistant must not assume.
  4. Output: Specify the format you can use: a checklist, table, short explanation, email draft or step-by-step plan.
  5. Quality check: Ask the assistant to identify assumptions, uncertainty or facts that need independent verification.

This structure is a starting point, not a rigid template. Simple requests need only a sentence or two. More consequential work benefits from more context and clearer constraints.

Example: turn a vague request into a useful brief

Vague: “Help me with a marketing plan.”

More useful: “I run a small home bakery in Worcester. Suggest a four-week marketing plan for a limited budget. Focus on local repeat customers, use Instagram and WhatsApp only, and organise the ideas by week in a table. Do not invent audience statistics or advertising prices. Finish with three measures I can track myself.”

The second prompt gives the assistant a real context, a defined task, practical constraints and a usable output format. The answer may still need editing, but it has fewer gaps to guess at.

Work in stages for complex tasks

Large requests often mix research, analysis and writing. Split them into stages: first ask for an outline, then supply or confirm the evidence, then request a draft, and finally ask for a critical review. This makes errors easier to spot and gives you control over important decisions.

If the first answer misses the mark, explain what is wrong and what should change. Iteration is normal. Keep the useful context, correct misunderstandings and narrow the next request rather than starting over every time.

Verify before you rely on the answer

AI systems can produce confident but incorrect statements, outdated details, fabricated references or calculations that look plausible. Treat the output as a draft or analysis aid, not automatic proof.

  • Check important facts against primary or authoritative sources.
  • Open cited links and confirm they support the exact claim.
  • Recalculate figures independently when money, safety or compliance is involved.
  • Do not paste passwords, private client records, patient information or confidential workplace material into a tool unless your organisation has explicitly approved that use.
  • Tell the assistant when it should say “I don't know” rather than fill gaps.

A prompt you can adapt

“I need help with [task]. Context: [relevant background]. The audience is [audience]. Please [specific action]. Keep these constraints in mind: [limits]. Return the result as [format]. If information is missing, ask me rather than guessing. Mark any assumptions and tell me which important claims I should verify.”

Save prompts that work, but revisit them when the task, audience or tools change. A reusable prompt is a starting point, not a guarantee of a correct result.
