Privacy Policy

Your privacy is important to us. This Privacy Policy explains how Boztik Creative Toolkit collects, uses, stores and protects information when you use our browser extension and website.

We designed Boztik Creative Toolkit with privacy as a core principle. Wherever possible, processing occurs locally on your own device instead of being transmitted to external servers.

Last Updated: October 2026

1. Information We Collect

Boztik Creative Toolkit has been designed to minimise the collection of user data. The extension does not require account registration and does not ask users to provide personal information before using its core features.

The public website's page-view counter stores the pseudonymous event data described below. Whether that identifier is personal information depends on applicable law and context; this policy does not classify it as anonymous or non-personal. Boztik does not sell personal information.

We do NOT collect:

The following list concerns the extension's core features; it does not describe the separate website page-view counter or third-party processing explained below.

  • Your full name
  • Email address
  • Phone number
  • Passwords
  • Payment information
  • Banking details
  • Government identification numbers
  • Health information
  • Biometric information
  • Personal communications
  • Browsing history
  • Search history
  • Location information
  • Advertising identifiers
  • User profiles

Boztik does not sell user information or build marketing profiles. Public website data is sent to Google Analytics and Google AdSense as described in Section 6.

Website page-view counter

On eligible public pages, a first-party script creates a random 32-character hexadecimal identifier if the `boztik_anon_session` cookie is not already present. The cookie is set for the Boztik website host, has the `SameSite=Lax` attribute and, on HTTPS, the `Secure` attribute. It expires 180 days after it is set; the script does not refresh that expiry while the cookie remains present. The identifier lets the page-view service associate eligible page views with the same browser over time for page-flow reporting.

For each eligible page view, the browser sends the page key and cookie identifier to Boztik's page-view API. When the endpoint is enabled and the request succeeds, the API records both an individual event (identifier, page key and server-generated timestamp) and an aggregate count for the page and day. The Worker source schedules cleanup of individual events strictly older than 90 days, in batches of up to 5,000 events per scheduled run. Because this cleanup is bounded and can fail or fall behind, an event may remain longer than 90 days. The repository configures the Worker to run scheduled maintenance every 10 minutes, but it cannot establish whether that Worker version and trigger are currently deployed and active. Aggregate daily counts are separate and are not removed by this event cleanup; no aggregate cleanup period is configured in the reviewed source. The 30-day page-flow report window is a reporting filter, not a deletion period.

The page-view API also reads the proxy-provided IP address for an in-memory rate-limit key; the reviewed application code does not write that address to the page-view event or aggregate tables. This counter does not include the browser's user-agent or referrer in its payload or those records. Hosting or network-platform logging outside the reviewed application source could not be verified. The counter is skipped when Do Not Track or Global Privacy Control is detected, and it does not run on private delivery pages or the Command Centre. This check applies only to this counter; it does not control the separately loaded Google tags described in Section 6.

2. Local Storage

The Boztik website and the Boztik Creative Toolkit extension store a very limited amount of data locally in your browser to make the experience convenient and persistent.

On this website, the assistant and UI use the browser's localStorage to keep temporary chat history and optional configuration. When you enter an API key to connect a third-party AI provider on this site, that key is stored only in your browser's localStorage.

If you install the browser extension, extension settings and preferences are stored locally by the extension using the browser's extension storage API (for example chrome.storage in Chromium-based browsers). In both cases, data is stored on your device and is not transmitted to Boztik-operated servers by default.

Examples of locally stored information:

  • Site assistant chat history (stored in localStorage on this site)
  • Optional AI provider connection keys that you add in your browser (stored locally only)
  • User preferences and extension settings
  • Achievement progress and usage counters shown in the UI
  • Any custom configuration saved by you in the UI

This locally stored information remains on your device until you clear it (for example by clearing site data or uninstalling the extension). It is not automatically uploaded to Boztik-operated servers unless an explicit feature in the future requires it and you are asked to opt in.

You can remove this information at any time by clearing your browser's site data, clearing localStorage via developer tools, or uninstalling the extension (which removes extension storage according to the browser's behavior).

3. Image Processing

Most image analysis is performed locally inside your browser.

Boztik Creative Toolkit does not permanently upload, archive or store the images you inspect.

When you choose to use external services such as Google Reverse Image Search, TinEye or Bing Visual Search, the selected image or image URL is sent directly to that third-party service at your request.

Boztik Creative Toolkit does not receive or retain this information.

4. Chrome Extension Permissions

Boztik Creative Toolkit only requests browser permissions required to provide its advertised features.

activeTab

Temporarily accesses the currently active webpage only after you interact with the extension. This allows image inspection and analysis of the page you choose.

contextMenus

Adds Boztik Creative Toolkit options to the browser's right-click menu for quick access to image tools.

downloads

Allows the extension to download an image only when you explicitly use the Download Original feature.

scripting

Allows the extension to inject scripts into the active webpage only when required for user-initiated features such as analysing images or extracting colour palettes.

storage

Stores extension settings and preferences locally on your own device.

These permissions are used solely to provide extension functionality and are never used to monitor users, collect personal information or track browsing activity.

5. Artificial Intelligence Services

Some features on this website and in the assistant are able to connect to third-party AI providers if you choose to enable them.

The current site implementation supports direct connections from your browser to the following providers when you supply and enable a provider API key in the UI:

  • OpenAI (ChatGPT-compatible APIs)
  • Anthropic (Claude)
  • Google (Gemini / Generative Language API)

How AI requests work on this site:

  • Requests are sent only after an explicit user action — for example when you click Connect, Test or Submit in the Creative Assistant UI, or when you send a prompt to the assistant.
  • When a request is made, your browser sends the prompt (and the built-in system prompt used to guide responses) directly to the selected provider's API endpoint. The request may include the API key you supplied in your browser.
  • API keys and prompts are sent directly from your browser to the provider. Boztik's site does not forward your key to any Boztik-operated server, and Boztik does not receive your API key when you connect a provider in the browser UI.
  • The site stores optional keys and a local copy of chat history only in your browser (localStorage) so the connection and chat persist between visits on the same device; these are not uploaded to Boztik-operated servers by the current site code.
  • Responses returned by the provider are displayed in your browser. Unless you explicitly opt in to a future feature that may upload or log prompts/responses, Boztik does not permanently store prompts, requests, responses or uploaded images on Boztik-operated servers.

Each AI provider processes requests according to its own Privacy Policy and Terms of Service. When you use a provider you accept that provider's handling of your data (prompts, responses and any content you include in requests).

If you do not want to use external AI services, the assistant continues to provide built-in guidance that runs entirely in your browser and does not require a provider connection.

8. Data Retention

Because Boztik Creative Toolkit does not collect personal information on Boztik-operated servers for its browser features, no extension user data is retained by us.

The public website page-view counter stores individual page events and aggregate daily counts as described in Section 1. The Worker source schedules bounded cleanup of individual events older than 90 days; events may remain longer if cleanup fails or falls behind. Whether the configured Worker and scheduled trigger are currently deployed and active cannot be verified from the repository. Aggregate daily counts are not part of this cleanup and have no configured deletion period in the reviewed source. The 30-day page-flow report window does not delete older events. Google Analytics and Google AdSense have separate processing and retention governed by their settings and policies, which cannot be verified from this repository.

Boztik Deliver, the separate private system used to send finished work to clients, stores delivery information needed to function — including the delivery ID and the client, project, and file details provided for each delivery — on Boztik-controlled Cloudflare infrastructure (D1 and R2). Files are removed through the delivery expiry cleanup process; delivery records and related analytics may remain after file removal. Their retention period is not specified here.

Any settings stored using the Chrome Storage API remain on your own device until you uninstall the extension or clear your browser's extension storage.
